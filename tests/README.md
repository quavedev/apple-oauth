Run node tests/node-compat.cjs /absolute/path/to/installed/node_modules on Node 24 and 26. Install the three Npm.depends dependencies in a disposable directory using a copy of the package npm-shrinkwrap.json and npm install --ignore-scripts. Tests use synthetic in-memory keys. They cover module loading, ES256 client secrets, RS256 identity verification, HS256, and rejection of wrong signature/issuer/audience/expiry. They do not verify live Apple sign-in, JWKS fetching, Cordova, or a complete Meteor application.
